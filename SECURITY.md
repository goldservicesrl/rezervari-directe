# Securitate

Problemele de securitate se raportează **doar** prin raportarea privată a vulnerabilităților de pe GitHub: fila **Security** a depozitului, apoi **Report a vulnerability**. Nu le deschideți ca issue public și nu le trimiteți pe e-mail.

Nu există o adresă dedicată și nu promitem un răspuns, o reparație sau un termen. Softul se oferă gratuit, așa cum este, fără suport.

Versiunile oficiale se publică doar pe pagina de versiuni a depozitului. Softul nu se actualizează singur: fiecare gazdă descarcă și urcă singură versiunea nouă.

# Security

Security issues are reported **only** through GitHub private vulnerability reporting: the repository's **Security** tab, then **Report a vulnerability**. Do not open them as a public issue and do not send them by email.

There is no dedicated address and no promise of a reply, a fix or a deadline. The software is offered free of charge, as is, without support.

Official versions are published only on the repository's releases page. The software does not update itself: each host downloads and uploads the new version themselves.
